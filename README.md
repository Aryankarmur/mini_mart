# Mini Mart — React E-Commerce Web Application

A responsive e-commerce web application built with React.js that allows users to browse products, search and filter items, view product details, manage a shopping cart, place orders, and explore account-related features.

This project was built as a practical frontend project to strengthen my skills in React, routing, reusable components, API integration, and building multi-page shopping flows.

## 📌 About the Project

Mini Mart is a React-based e-commerce application designed to simulate a modern online shopping experience.

The application uses product data from the DummyJSON API and includes multiple user flows such as product discovery, search, category browsing, product details, cart management, authentication screens, address handling, payment flow, and order viewing.

The project helped me practice building reusable React components, managing application navigation, working with external API data, and creating a responsive shopping experience.

---

## ✨ Features

- Browse products from an external API
- Search for products
- Browse products by category
- View detailed product information
- Add products to the shopping cart
- View and manage cart items
- User login and sign-up interfaces
- User profile section
- Address management
- Payment flow UI
- Order viewing
- Responsive layout
- Reusable React components
- Client-side routing
- Lazy loading of application pages
